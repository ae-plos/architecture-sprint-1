# Mesto - приложение галереи с пользователями и фотографиями
Функциональность Mesto:
1. Загрузка фотографий
2. Удаление фотографий
3. Сбор и учёт лайков под фото
4. Создание профиля и его редактирование

## Уровень 1. Проектирование
> Выберите фреймворк для создания микрофронтендов и опишите решение в удобном вам виде.

Все части приложения написаны с использованием React 
    => для того что бы минимально переписывать существующцю кодовую базу будет продолжнаться использоваться он
    => для разбиения на мирофронтенды не требуется использовать другие фрейворки в текущий момент, и не предвидится в дальнейшем
    => из двух популярных фреймворков Module Federation и Single SPA стоит выбрать Module Federation, тк сильное преимущество Single SPA не предвидится в горизонте планирования


## Уровень 2. Планирование изменений
> Предоставьте структуру кода и обоснуйте своё решение в Readme.md. Вы можете создать необходимые проекты, добавить в них подкаталоги для контролов и логики, разложить код исходного проекта по ним, но запускать проекты не нужно.

Технический анализ исходного кода проекта, позволяет выделить слабо сзвязные части проекта (соответсвующие DDD):
- host - неоходимый в Module Federation микрофронт - основная точка старта приложения
- auth - микрофронтерд для реализации основного перенаправления неавторизированных пользователей и страницы авторизации
- users - микрофронтенд для реализации функционала управления пользователями. Регистрация, информационного сообщения об регистрации, редактирование профиля и аватарки
- gallary - микрофронтенд для реализации функционала отображения фотографий, открытия фотографии, выставление или снятие "лайка", добавления фотографии.
- main - микрофронтенд для управления общими элементами страницы таких как заголовок, колонтитулы, разметка страницы и управляющее приложение. Дополнительно размещаются общие компоненты.

Согласно структуре, микрофронты находятся в  ```frontend/microfrontend```

### Запуск (3-й уровень частично реализован)

1. `cd auth && npm run start`
1. `cd gallary && npm run start`
2. `cd main && npm run start`
3. `cd users && npm run start`
4. `cd host && npm run start`

Для проверки перейти на страницу [http://localhost:8080](http://localhost:8080)
